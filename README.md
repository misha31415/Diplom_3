# 🖥 UI-тестирование Stellar Burgers

## 📋 Описание

Проект по автоматизации тестирования веб-приложения Stellar Burgers.  
Покрытие ключевых пользовательских сценариев: регистрация, вход, восстановление пароля,  
работа конструктора бургеров.

---

## 🛠 Технологии и инструменты

| Технология | Версия | Назначение |
|------------|--------|------------|
| **Java** | 11 | Язык разработки |
| **JUnit 4** | 4.13.2 | Фреймворк для тестирования |
| **Selenium** | 4.15.0 | Автоматизация браузера |
| **WebDriverManager** | 5.6.2 | Управление драйверами |
| **Allure** | 2.27.0 | Отчётность |

---
## 🧪 Что покрыто тестами

### Регистрация
- Успешная регистрация пользователя
- Ошибка при регистрации с паролем менее 6 символов

### Вход
- Вход по кнопке «Войти в аккаунт» на главной
- Вход через кнопку «Личный кабинет»
- Вход через кнопку в форме регистрации
- Вход через кнопку в форме восстановления пароля

### Конструктор
- Переход к разделу «Булки»
- Переход к разделу «Соусы»
- Переход к разделу «Начинки»

### Восстановление пароля
- Открытие страницы восстановления
- Отправка формы с валидным email
- Переход по ссылке «Войти»
